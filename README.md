# Transport Races

Simulador de carreras de camiones de carga. **El primero en llegar a meta gana.**

Inspirado en Cargo Transport Simulator, pero en modo carrera: tú y tres rivales salen del depot con un trailer. Completa **2 vueltas** del circuito industrial. Quien cruce la meta primero, gana.

## Cómo se juega

1. Elige camión:
   - **Halcón** — más veloz, menos agarre
   - **Titán** — equilibrado
   - **Mamut** — lento y estable
2. Pulsa **Correr**
3. Lleva la carga a meta sin salirte del asfalto

### Controles

| Tecla | Acción |
| --- | --- |
| W / ↑ | Acelerar |
| S / ↓ / Espacio | Frenar |
| A / ← | Girar a la izquierda |
| D / → | Girar a la derecha |
| P / Esc | Pausa |

En el teléfono: panel izquierdo para girar, **Gas** y **Freno** a la derecha.

Mando: palanca izquierda para girar, gatillo derecho para acelerar, gatillo izquierdo para frenar.

## Reglas

- 4 camiones en pista (tú + 3 IA: Ruta Norte, Delta Cargo, Sierra Haul)
- Hay que pasar los checkpoints en orden (no vale recortar la vuelta)
- Fuera del asfalto el camión pierde velocidad
- El ranking se decide por quién termina antes las 2 vueltas

El juego se construyó para jugarse en el navegador (vista 3D, circuito cerrado, rivales y entrega a meta).
